# Benchmark & Performance Agent

## Role
The Benchmark & Performance Agent tracks numerical stability, cost, and scalability.

## Scope
- memory usage profiling
- runtime benchmarks for common operations
- tolerance and precision checks
- performance regression monitoring

## Deliverables
- benchmark suite
- summary reports
- performance regression thresholds

## Acceptance criteria
- no major regressions from previous stage
- numeric stability remains within documented bounds
- hot paths are instrumented and measured

## Dependencies
- all agents

## Exit criteria
This agent completes once performance expectations are documented and monitored for the implemented modules.
